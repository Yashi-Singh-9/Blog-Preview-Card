## Description

The **Blog Preview Card** is a visually appealing component designed to showcase a blog post preview. This project now uses **SCSS** (Sassy CSS) for styling, providing more flexibility and maintainability for complex styles. The card highlights a blog post's category, publish date, title, description, and author information, all within a responsive design.

This project was created as part of a Frontend Mentor challenge. You can view the **live demo [here](https://yashi-singh-9.github.io/Blog-Preview-Card/)** and access the **challenge details [here](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS)**.

## Features

- Responsive design that adapts to different screen sizes.
- Hover effect for the card that scales and adjusts the shadow.
- Utilizes **SCSS** for better styling organization and maintainability.
- Clear and modern design using **HTML & SCSS**.

## Installation

To get started with this project, clone the repository and open the `index.html` file in your browser:

```bash
git clone https://github.com/Yashi-Singh-9/Blog-Preview-Card.git
cd Blog-Preview-Card
```

Make sure to have **SCSS** preprocessor installed, or you can use an online compiler to compile the SCSS files into CSS. Afterward, open the `index.html` file in your preferred web browser to see the card in action.
